级别与截止时间规则

  • 每个进程有一个常规级别（默认 INFO），网页可随时修改并带版本号下发。
  • 开启临时 DEBUG 时下发的是绝对 UTC 截止时间；续开会产生新的截止时间，worker 直接以新值为准。
  • DEBUG 期间收到的新常规级别先挂起（pending），到期后才应用。
  • 即使配置通道中断（暂停下发 / 管理服务重启或宕机），worker 也按最后收到的截止时间自行结束 DEBUG，恢复最后收到的常规级别（或调试期间挂起的新级别）。
  • 重连后若截止时间已过，worker 跳过该 DEBUG 窗口，不会重新进入 DEBUG。
  • 管理端把配置（含原截止时间、暂停状态）持久化到数据卷，重启后沿用原截止时间。

主要 API

GET  /api/overview
POST /api/workers/{id}/level                 {"level":"WARNING"}
POST /api/workers/{id}/debug/start           {"seconds":30}
POST /api/workers/{id}/debug/renew           {"seconds":120}
POST /api/workers/{id}/debug/cancel
POST /api/workers/{id}/pause | /resume
POST /api/workers/{id}/sample-logs
POST /api/sample-logs/write-all
GET  /api/workers/{id}/logs?limit=200
GET  /config/{id}                            (worker 轮询；暂停时 503)
GET  http://localhost:8001/local/state       (直连 worker1)
GET  http://localhost:8002/local/state       (直连 worker2)
